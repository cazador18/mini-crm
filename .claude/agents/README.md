# Custom Subagents

Сюда добавляется минимум один свой субагент для проекта.

Пример структуры:
```
.claude/agents/code-reviewer.md
```

Идеи из ТЗ:
- Агент-ревьюер кода (проверка слоёв controller/service/repository на SOLID)
- Агент для исследования части кодовой базы (например, анализ покрытия тестами)

После создания — описать в корневом README: что делает агент и как вызывается.
