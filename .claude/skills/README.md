# Custom Skills

Сюда добавляется минимум один свой Skill для проекта.

Пример структуры:
```
.claude/skills/crud-endpoint-generator/SKILL.md
```

Идеи из ТЗ:
- «Сгенерировать CRUD-эндпоинт по шаблону» (controller + service + repository + DTO под новую сущность)
- «Проверить README» (валидация, что README соответствует чек-листу DoD)
